Thiết lập Firebase cho QC Lab

Tài liệu này dành cho quản trị viên thiết lập đồng bộ Firebase Realtime Database lần đầu.

  1. Trong Firebase Console, vào Authentication → Sign-in method, tắt Anonymous và bật Email/Password.
  2. Vào Authentication → Users, tạo một tài khoản cho mỗi máy/người dùng và lưu lại User UID.
  3. Trong Realtime Database → Data, tạo ACL theo mã phòng đang dùng: qclab-acl/{mã-phòng}/{UID}: true.
  4. Vào Realtime Database → Rules, dán toàn bộ Rules bên dưới và Publish.
  5. Quay lại QC Lab → Cài đặt & Đồng bộ, nhập mã phòng, email/mật khẩu và dán Firebase config từ Project settings → Your apps.

Không thay tên $labCode hoặc $uid. Mỗi tài khoản chỉ có quyền với mã phòng được đặt trong ACL.

Firebase Rules

{
  "rules": {
    ".read": false,
    ".write": false,
    "qclab-acl": {
      "$labCode": { "$uid": { ".read": "auth != null && auth.uid === $uid", ".write": false } }
    },
    "qclab-shared": {
      "$labCode": {
        ".read": "auth != null && root.child('qclab-acl').child($labCode).child(auth.uid).exists()",
        ".write": "auth != null && root.child('qclab-acl').child($labCode).child(auth.uid).exists()",
        ".validate": "newData.hasChildren(['_ts'])",
        "_ts": { ".validate": "newData.isNumber()" },
        "_client": { ".validate": "newData.isString()" }
      }
    }
  }
}
