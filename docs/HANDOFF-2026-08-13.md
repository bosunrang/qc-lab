## Phần đã tách sang TypeScript

Đã có lớp TypeScript cho domain/application/presentation của Dashboard, Reagent,
Manage cấu hình, Settings, Users/Audit, Reports, Sigma, NCE, storage/Firebase,
LIS và nhiều helper Entry. UI legacy vẫn còn ở `assets/modules/` và gọi các API

phải toàn bộ trang hoặc toàn bộ runtime đã hết JavaScript global.

## Việc nên làm tiếp: luồng Nhập QC (Entry)

Đây là lát chính tiếp theo vì nó chạm vào dữ liệu vận hành thực:

`nhập giá trị → kiểm tra → ghi điểm/hủy điểm → Westgard + cache → save/sync → audit/NCE`.

Nên làm theo lát nhỏ, không chuyển nguyên `pageEntry()` một lần.

### Điểm bắt đầu cụ thể

1. Đọc `src/application/entry/entry-service.ts`: service đã có
   `preparePointInput`, `recordPoint`, `voidPoint`, cùng các helper Entry.
2. Đọc controller legacy `assets/modules/entry-routes.js`, đặc biệt:
   - `entryInlineSave()` và `entryInlineSaveCommit()` (khoảng dòng 326);
   - `voidQcPoint()` và `confirmVoidQcPoint()` (khoảng dòng 382);
   - `pageEntry()` chỉ là phần dựng UI lớn, để sau.
3. Lát ưu tiên đầu tiên: tách phần điều phối **ghi một điểm QC** thành một
   application command có kết quả/effects rõ ràng. Controller chỉ lo modal,
   hiển thị feedback, gọi audit/save/rerender theo effects.
4. Sau khi test ổn, làm tương tự cho **hủy điểm QC + tạo/tái sử dụng NCE**.
   Đây là phần rủi ro cao: không thay đổi policy khóa kỳ, audit, NCE rerun hoặc
   cache chỉ để làm code đẹp.

## Hợp đồng bắt buộc phải giữ

- Mọi thay đổi điểm QC phải tôn trọng `PeriodService`/period lock.
- Ghi hoặc hủy điểm QC phải giữ audit trail, NCE liên quan và kết luận Westgard.
- Save dữ liệu QC phải invalid cache đúng phạm vi. Đừng thay bằng
  `save({clearDerived:false})` cho mutation điểm QC nếu chưa hiểu rõ hợp đồng
  cache hiện hành.
- Không để code mới trong `src/domain/` đọc DOM, Firebase, `localStorage` hoặc
  biến `state` global. Truyền dependency qua factory/đối số; chỉ compatibility
  adapter mới được nối vào globals.
- Sau khi đổi file trong `src/`, phải build và commit cả
  `assets/generated/modular-pilot.js`.
- Nếu sửa JavaScript legacy hoặc `index.html`, cập nhật cache-busting `?v=` cho
  file đã sửa; giữ thứ tự script load.
